# Quick Start — 10 minutes to first trial link

1. **(1 min)** Open the app with `?demo=1` once to arm the Demo Tools bar.
2. **(1 min)** Click **Seed demo event** — fresh flagship event, fresh brief
   codes, zero confirmation rows.
3. **(2 min)** Open the event → Vendors → pick the caterer (Capital
   Rotisserie) → copy the brief link from the cockpit row.
4. **(1 min)** Copy the matching message from VENDOR_TRIAL_SCRIPT.md (real
   vendor or stand-in), paste the link, send it over SMS or email.
5. **(0 min)** Wait. Do not explain anything.
6. **(3 min, after response)** Open the cockpit row → screenshot → apply the
   offered action (Save on-site contact / Mark confirmed / Add to log) →
   screenshot again.
7. **(2 min)** Fill one row in EVIDENCE_TRACKER.csv while it's fresh.

Repeat with the venue, DJ, photographer, and rentals vendors to cover ≥3
categories. Reset anytime with **Seed demo event** — old links 404
automatically. Score with TRIAL_SCORECARD.md when you have 5+ rows.
