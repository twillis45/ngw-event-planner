# Every Layer, Rated

Thirty intelligence layers — driven live in both apps, then cross-checked line-by-line against the engine code and **every code claim re-verified in source before it was ranked**. The pattern: the **math engines** are mostly sound; the **copy and classification that frame them** is where it breaks. Some deep-code findings proved overstated on verification and were downgraded — that calibration is in the notes, because an audit about honesty has to hold itself to it. Ratings below recomputed 2026-07-10 and 2026-07-11 against the shipped fixes.
