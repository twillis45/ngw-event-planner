## What broke when I pushed the edges

Live, in-app, on the seeded crab feast. This is the category the leaders win by the widest margin.

**200 crab pickers on a 75-guest event → `$5,198–$9,240`** — ✓ fixed 07-10
The app priced crabs for 200 pickers when only 75 people exist. No check that pickers ≤ guests. Fat-finger "200" for "20" and you get a $9k order with zero warning — and the guests tile still calmly reads 75. **Now:** pickers are clamped to the guest count for coverage math, with the reason shown ("Pickers can't outnumber your 75 guests — using 75 for coverage."), and the host's typed input is never silently overwritten.

**Two events named "My Crab Feast" — no longer unreliable to load** — ✓ fixed 07-10
Was: with a sample and a custom event sharing a name, selecting the correct one was unreliable even for the developer — a host could order crabs against the wrong plan and never know. **Now:** every seed/demo event carries a "Sample" badge (the same id-based mechanism legacy's own "Demo" badge already used), so an exact name+venue collision stays distinguishable.

**A 6-year-past event → "this one is behind you" *and* "3 things need you"** — ✓ fixed 07-10
Was: the phase engine correctly said the event was over while the action tile still nagged "3 things need you" — two layers disagreeing. Fixed: the action list agrees with the phase engine — a wrapped event surfaces no "next actions" at all.

**No upper clamp anywhere** — ✓ fixed 07-10
Was: 5,000 guests scaled the food/crab/budget bands linearly into fantasy figures with no "that seems high — did you mean 50?" Fixed: never clamps the number (a host may genuinely run something that large) — but now names it honestly, wherever the estimate is shown. Not fully leader-level: a leader would gate on the out-of-range number, not just note it.

**Credit: 0 guests degrades honestly**
Clear the count and the dollars vanish with "set a real count and the dollars appear" — the `hasRealCount` gate refuses to fabricate. The one edge both apps handle like a leader would.
