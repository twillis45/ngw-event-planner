Hero 9/10 · was 7*
Capped by
Relevance, not correctness. The hero provably always asks something real across 273 states — and it is unprovable that “Which song for the vals, and who plays it?” is the sentence that host needed.
To reach 10
A host panel. Real hosts judging whether the question was the one they needed.Needs people, not code
How to run it
  1. Freeze the corpus first. The rescore enumerated 273 hero states (event type × countdown stage). Export that exact set so the panel judges what the 9 was derived from — a panel on a different set re-scores a different thing.
  2. Pre-register the bar before anyone sees a screen. Write down the threshold that earns the 10th point — the ranking board's own discipline. A panel run without a stated bar produces a result that cannot fail, which is worth nothing.
  3. Recruit first-time hosts, not planners. Stage 9 already mandates a first-timer seat on the promotion board; reuse that recruitment rather than opening a second channel.
  4. Ask one question per state — “is this the thing you would want to be asked right now?” with yes / no / right thing, wrong time. Not a 1–5 rating; a rating cannot fail the bar.
  5. Record it as a dated rescore in docs/audits/, citing the response counts. The 10 is claimable only from measured host answers.

Done when — a dated panel result clears the pre-registered bar. Nothing in the engine changes.
